# fenifut-static

Plain HTML site for FENIFUT. No backend, no build step. Served with GitHub Pages from `main` (root).

- `index.html` – home
- `acerca/` – about (served at `/acerca`)
- `estado-financiero/` – redirects `/estado-financiero` to the transparency PDF
- `css/app.css` – Tailwind output, generated once from the HTML (regenerate only if classes change)
